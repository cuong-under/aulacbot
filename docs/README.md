# AULACBOT Documentation

Two documentation trees live here.

## Upstream's (`docs/adr/`, `docs/design/`, `docs/media/`)

Read-only copies of agentes.chat's own documentation: 185 architecture decision records, design
notes and media. They describe why upstream is built the way it is. Do not edit them; a change here
would conflict on every sync and is not ours to make.

## AULACBOT's

| Folder | Contents |
| --- | --- |
| `project/` | Overview, license and attribution obligations, development governance |
| `architecture/` | Repository structure and monorepo architecture, as audited |
| `development/` | Windows setup, environment variables |
| `decisions/` | AULACBOT ADRs (ADR-001 architecture, ADR-002 upstream sync) |
| `branding/` | AULACBOT mark, palette, app icons, social cards and lockups |
| `upstream/` | Baseline, ownership map, sync procedure, conflict resolution, customization registry, sync history, impact reports |

Start with `project/PROJECT_OVERVIEW.md`, then `upstream/OWNERSHIP_MAP.md`.
