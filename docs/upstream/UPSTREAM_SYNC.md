# Upstream Synchronization

## Principle

AULACBOT must be able to take any future agentes.chat commit for years without forking again. That
holds only while: history is shared, `upstream` is a permanent remote, sync merges are real merges,
and AULACBOT edits stay outside upstream-owned files whenever a config seam exists.

## Remotes

```powershell
git -C D:\AulacBot\aulacbot remote -v
# upstream  https://github.com/agentes-chat/agentes-chat.git
# origin    https://github.com/<owner>/aulacbot.git      (pending owner decision)
```

All AULACBOT development pushes to `origin` only. Nothing is ever pushed to `upstream`.

## Sync procedure

### 1. Fetch and inspect

```powershell
cd D:\AulacBot\aulacbot
git fetch upstream --prune --tags
git log --oneline --no-merges HEAD..upstream/main
git diff --stat HEAD...upstream/main
git diff --name-status HEAD...upstream/main
```

`HEAD...upstream/main` (three dots) diffs against the merge base, which is what actually changed
upstream since the last sync.

### 2. Classify every changed file

For each path in `--name-status`, look it up in `OWNERSHIP_MAP.md` and cross-check
`CUSTOMIZATION_REGISTRY.md`. Anything appearing in both is a **predicted conflict** — record it
before merging.

### 3. Branch and merge

```powershell
git switch develop
git pull --ff-only            # or nothing, if develop is only local
git switch -c upstream-sync/2026-11-16
git merge upstream/main
```

Never `git rebase`, never `git merge --squash`, never `git push --force`.

### 4. Resolve conflicts

Follow `CONFLICT_RESOLUTION.md`. Never take one side wholesale. A conflict in an upstream-owned file
that AULACBOT never edited is a signal to re-read what changed, not to force `--theirs`.

### 5. Validate

```powershell
bun install --frozen-lockfile --linker=hoisted
bun run rebrand:check       # every mechanical file still says AULACBOT, not agentes.chat
bun run check:brand         # palette, wordmark, font, desktop ink, embedded pictures
bun run brand:drift         # which handcrafted brand file the merge touched
bun run typecheck
bun run lint
bun run check:boundaries
bun run check:licenses
bun run check:migrations
bun test
```

### 5b. Repair the brand

`bun run rebrand:check` lists two kinds of file after a merge:

- **mechanical** — the diff upstream made is only `agentes.chat` text. `bun run rebrand` rewrites
  them; nothing else is touched.
- **unclassified** — a path that says `agentes.chat` and is in neither the mechanical nor the exempt
  list. Upstream added or renamed it. Read it, decide whether it is ours to rename or must stay
  upstream's, then add it to the right list in `scripts/brand/manifest.json` and re-record with
  `bun run brand:manifest <upstream-sha>`.

`bun run brand:drift` names every handcrafted brand file the merge changed. Each one is a decision:
keep upstream's version, keep ours, or merge the two by hand. When the result is the brand you want,
`bun run brand:manifest` records the new baseline in the same commit as the sync.

Never run a blanket search-and-replace over the tree to "fix" the brand: 463 of the 726 changed files
are hand-made, and a rewrite flattens them.

If `bun.lock` changed upstream, the install must succeed **without** `--frozen-lockfile` first, then
the new lock is committed by the sync itself — never regenerated by hand.

### 6. Report

Write `docs/upstream/reports/YYYY-MM-DD-sync.md` using the template in that folder, add a row to
`SYNC_HISTORY.md`, and open a pull request into `develop`.

### 7. Merge

Only after review. `main` receives the sync later, through a release PR — never directly.

## What counts as a risk

| Risk | Signals |
| --- | --- |
| LOW | Docs, `docs/adr/**`, independent module, no AULACBOT customization nearby |
| MEDIUM | Shared packages, API contracts, dependencies, build config |
| HIGH | Database schema or migrations, agent runtime, auth/authz, Model Gateway, core interfaces, any file in the Customization Registry |
| CRITICAL | Security fix requiring immediate uptake, data-loss risk, auth bypass, breaking change |

Git reporting "no conflict" does **not** mean "safe". A silent semantic change in a file AULACBOT
relies on is a conflict the merge tool cannot see.

## Cadence

- Fetch weekly, even when no sync is planned — it keeps the diff small and the report honest.
- Sync at least monthly, or immediately for a CRITICAL security release.
- Always before a release branch is cut.

## Automating the watch (later)

A GitHub Actions workflow or script may be added to detect new upstream commits and open a draft
sync branch. In the bootstrap phase nothing is automated: no auto-merge, no auto-deploy, no
auto-overwrite. See `.github/` for what upstream already runs — do not modify upstream workflows.
