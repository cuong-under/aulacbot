## F. Follow-ups

- [x] Point the desktop updater at AULACBOT (CUSTOM-015). With upstream's endpoint an install
      would download upstream's signed bundle and replace itself with agentes.chat. Both paths now
      live on `github.com/cuong-under/aulacbot`: the Tauri updater reads the rolling `desktop-latest`
      `latest.json`, and the app's own check reads GitHub's REST API and rejects any download whose
      URL is not under that repo's `/releases/download/`.

- [x] Serve the installer from a rolling tag (CUSTOM-016). `releases/latest/download/install.sh`
      would break on the first `desktop-v*` release (it carries no installer); `install.sh` and the
      15 help pages now use `releases/download/installer-latest/`, rolled by `release-install`.

- [x] Removed the two upstream-only workflows (2026-11-21): `.github/workflows/cla.yml` (asked
      contributors to sign `agentes-chat/agentes-chat`'s CLA and wrote to its `cla-signatures`
      branch — neither exists on the fork) and `.github/workflows/release-setup.yml` (published
      `@agenteschat/setup` to npm through upstream's Trusted Publisher, which the fork cannot use).
      `CLA.md` and ADR 0180 stay in the tree as upstream history; only the automation is gone.

- [x] CI now runs on `develop` too. The fork's default branch is `develop` (upstream's `main` is
      still the sync base), and `ci.yml` listened only to `push` on `main`: a push to the working
      branch ran no check at all. `branches: [main, develop]` added, and the image `build` job is
      narrowed to `main` and tags so a `develop` push cannot try to publish a `:edge` image.

- [ ] Decide on `apps/desktop/src/i18n/locales/*.json` `report.*`: they still name `agentes.chat`
      because reports go to the upstream team. If AULACBOT ever runs its own report endpoint,
      change them together with `DEFAULT_URL` in `problem_report.rs`.
- [x] `brand:drift` / `rebrand:check` / `check:brand` all pass after the manifest was re-baselined
      on the new upstream tip and the manifest stopped hashing itself (CUSTOM-013).
- [x] Full gate run on 2026-11-21: `bun install --frozen-lockfile --linker=hoisted`,
      `check:boundaries`, `check:licenses`, `check:migrations` and `build` all pass.
- [ ] `vi` stays `ready: false`: finishing `vi.json` (18k shared keys) is what would let the
      language appear in a picker on the web and the phone. The desktop already offers it.
