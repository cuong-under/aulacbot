## Applications

### `apps/server` — 504 files

Bun + Hono. `package.json` name `@agenteschat/server`.

| Path | Role |
| --- | --- |
| `src/main.ts` | Self-host entry point |
| `src/start.ts` | `startServer`: config, DB, migrations, adapters and module overrides, HTTP + WS, workers |
| `src/app.ts` | `createApp`, testable via `app.request` |
| `src/routes/app/*` | Private web-app API under `/api/app/*` (`createRoute`, cookie session + CSRF) |
| `src/operator/*` | Operator API on its own listener, `/api/operator/v1` |
| `src/auth.ts` | Better Auth at `/api/auth/*` |
| `src/realtime/ws.ts` | WebSocket at `/api/ws?orgId=` |
| `src/workers.ts` | Outbox job workers |
| `src/freeze-watch.ts` | Worker-thread watchdog for main-thread stalls |

Dev on port 3000 (`bun --env-file=../../.env --watch src/main.ts`); builds with `bun build
--target=bun`.

### `apps/web` — 1348 files

Vite 8 + React 19 + TanStack Router/Query. `src/` splits into `api`, `app`, `auth`, `chat`,
`components`, `fonts`, `hooks`, `i18n`, `lib`, `pages`, `realtime`, `routes`, `screen`, `types`.
Two build inputs: `index.html` (the app) and `screen.html` (the agent's screen for the phone app).
Dev on port 5173, proxying `/api` (WebSocket included) to port 3000.

### `apps/desktop` — 188 files

Tauri 2. `src-tauri/` is Rust: `main.rs`, `lib.rs`, `servers.rs`, `local_server.rs`, `discover.rs`,
`tailscale.rs`, `deep_link.rs`, `tray.rs`, `notch.rs`, `workspaces.rs`, `cookies.rs`, `runners.rs`.
`tauri.conf.json` declares product `agentes.chat`, identifier `chat.agentes.desktop`, three windows
(`popover`, `welcome`, `prefs`), deep-link scheme `agenteschat`, and updater endpoints pointing at
`app.agentes.chat`. `externalBin` bundles `agentes-runner` and `agent-browser`.

Windows build tooling: WebView2 + a Rust toolchain (`cargo` is installed on this machine).

### `apps/mobile` — 1149 files

Expo SDK 58 / React Native 0.88 with `expo-router`. Config is `app.config.ts` (there is no
`app.json`); bundle ids `chat.agentes.app[-variant]`, scheme `agenteschat`, `eas.json` with
development, preview and production profiles. Native projects are generated by `expo prebuild` and
never committed. `src/` splits into `agent`, `computer`, `features`, `i18n`, `lib`, `providers`,
`sky`, `ui`.

**Status: source only.** No APK, no store listing and no published mobile release exist in this
repository. Do not describe a released mobile app.

## Dependency boundaries

- `apps/*` and `packages/*` never import `ee/` or `@agenteschat/cloud` — enforced by
  `bun run check:boundaries` (ADR 0002, ADR 0180).
- Every `apps`/`packages` file is public, comments included; internal planning ids and private
  paths fail the same check.
- AULACBOT code must stay outside this direction: upstream never imports AULACBOT.
